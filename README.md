### Más información

- **Programa y bibliografía.**  Se pueden consultar en  [este enlace](Programa-1ro2018.pdf).
- **Correlatividades.**  De acuerdo con el régimen de correlatividades vigente, para cursar esta materia es necesario tener aprobados los trabajos prácticos de Análisis I.
- **Inscripción.**  Para poder ser incluido en las Actas de Trabajos Prácticos, es necesario haberse inscripto en la materia, vía el [Sistema de Inscripciones](https://inscripciones.exactas.uba.ar/exactas/) de la Facultad, y haber completado la encuesta de evaluación docente.
- **Régimen de aprobación.**  Para aprobar esta materia hay que aprobar un examen prefinal al final del cuatrimestre. El mismo tendrá una instancia de recuperación.
- Se recuerda que es obligatoria la lectura de las [normas de higiene y seguridad](http://www.dm.uba.ar/varios/normseg.html).
